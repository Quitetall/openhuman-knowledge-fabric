# Second-registry fixture

A deliberately different identifier registry — prefix `AC-` rather than `OH-`, and no `LOT`
namespace — used only by `tests/ontology/registry-separability.test.ts` to show that the product
compiles and packs a registry other than OpenHuman's, and to record exactly where it still
cannot (KF-SAS-RQ-139, SAS §100.3). Derived from `registries/openhuman/`; it is not a shipped
registry and describes no real organization.
