Purpose:
This worksheet models the joint impact of (A) committed reserved capacity phasing vs pay-as-you-go (PAYG) pricing decisions and (B) accelerated hiring (platform + infra) on unit economics and run-rate margin. Use this to decide whether to: take earlier multiyear commit discounts to lock price, or remain PAYG while hiring to hit faster feature velocity.

Assumptions (base inputs):
- Fiscal baseline: FY27 starting M1 = 2027-01-01. Currency = USD.
- Average hosted API price (PAYG): $0.035 / 1k tokens (generation), $0.002 / embedding unit.
- Typical long-running customer mix (model mix): 60% lighter quantized models (e.g., 7B/13B), 40% large-context 70B variants.
- Committed discount bands: 1mo no-commit PAYG; 12mo commit = 15% off PAYG; 24mo commit = 24% off PAYG; 36mo commit = 30% off PAYG.
- Reserved GPU cost proxy (effective per-token): $0.010 / 1k tokens when fully utilized at steady-state; actual varies with utilization.
- Hiring role buckets and blended fully-burdened cost (annual): SRE = $240k, Infra Eng = $220k, Platform Eng = $200k, Applied ML infra = $260k, Product Ops = $150k.
- Ramp hires phased over 4 quarters. Hiring lead time assumed 10 weeks to productivity ramp.
- Expected additional throughput per infra hire (steady-state): 5% capacity uplift per infra role; per SRE = 3% reliability headroom enabling 2% RU (revenue uplift) via fewer throttles.

Scenarios (summary):
1) Conservative: No commit, PAYG pricing, standard hiring cadence (+8 net hires in FY27).
2) Accelerate Hire: PAYG but hiring accelerated (+20 net hires in FY27) to prioritize features & reliability; higher opex early.
3) Commit Now: Sign 24mo commit at -24% price, standard hiring cadence (+8 hires).
4) Commit + Accelerate: 24mo commit + accelerated hiring (+20 hires).

Quick sensitivity outputs (annualized, illustrative):
- Revenue uplift (growth from product improvements + reliability): Conservative = +12% YoY; Accelerate Hire = +22% YoY; Commit Now = +12% YoY; Commit + Accelerate = +24% YoY.
- Effective gross margin (token unit economics only, ignoring non-CC expenses):
  * PAYG base (no commit): unit margin = price - infra-per-token = $0.035 - $0.010 = $0.025 / 1k tokens (71% gross margin).
  * 24mo commit price = $0.035 * (1 - 0.24) = $0.0266 => margin = $0.0266 - $0.010 = $0.0166 (62% gross margin).
  * Note: If commit enables higher utilization, effective infra-per-token drops to $0.008 => margin improves.

Headcount and cost phasing (quarterly extract):
- Base (standard hiring = +8 hires): Q1 hires: 2 (Platform, Infra), Q2: 3 (Infra x2, SRE), Q3: 2 (Applied ML, Product Ops), Q4: 1 (Engineering ops).
- Accelerated (+20 hires): Q1: 6, Q2: 6, Q3: 5, Q4: 3.
- Blended FY27 incremental payroll expense:
  * Standard hiring incremental run-rate: $1.66M annualized incremental payroll (includes onboarding ramp prorations).
  * Accelerated incremental run-rate: $4.1M annualized incremental payroll.

Breakeven analysis (commit discount vs hiring cost):
- Revenue uplift required to offset committing early (expressed relative to PAYG) for 24mo commit:
  * Annualized discount benefit (if current run-rate tokens = 20B 1k-token units / year): savings = 20B * ($0.035 - $0.0266) = 20,000,000 * $0.0084 = $168k annual.
  * If accelerated hiring +20 adds $4.1M opex, the commit savings are small compared to hiring delta. Therefore: committing solely for small unit-price savings does not justify near-term big hiring. Commit value grows if token volume >>20B or if commit allows capacity consolidation reducing infra-per-token.

Model-mix sensitivity (impact on per-token infra cost):
- If we shift to more quantized models (70% small / 30% large) infra-per-token goes down 12% (from $0.010 to $0.0088).
- If large-model usage increases (30% small / 70% large) infra-per-token rises to $0.0126.
- Commit discounts compound with model-mix benefits — e.g., commit + quantization move yields margin >> PAYG baseline.

Cashflow / runway impact (first 12 months):
- Commit Now requires deposit / payment schedule. 24mo commit estimated up-front/quarterly prepayment need: ~$420k/q in reduced invoices vs PAYG (conservative estimate), but typically commit sales require top-of-contract cash flow changes.
- Accelerated hiring increases monthly burn by ~$280–350k during peak ramp months.

Decision heuristics (recommendation framework):
- If near-term cash runway is tight (<9 months) => avoid large commit prepayments and prioritize cash-preserving standard hiring cadence.
- If token run-rate is already >50B 1k-units/year or committed customers justify reserved capacity => prioritize commit (24–36mo) to secure kernel-level discounts and capacity guarantees.
- If growth priority is product velocity/reliability (sales feedback points to feature-driven expansion), the value of accelerated hiring (even at higher opex) can unlock >15% incremental ARR growth that dwarfs modest unit price savings.
